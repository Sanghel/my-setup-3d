# my-setup-3d

Recreación interactiva de mi habitación y setup en 3D, estilo **voxel**, construida con
React Three Fiber. Cada objeto del cuarto se puede seleccionar: la cámara vuela hacia él,
se puede rotar y hacer zoom, y se abre un panel con sus detalles.

## Stack (planeado)

- Vite + React + TypeScript
- three.js vía React Three Fiber + drei
- postprocessing (bloom / pixelado)
- zustand
- Modelos: voxeles generados por código + MagicaVoxel
- Deploy: Vercel
